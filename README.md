**Introducción y descripción del conjunto de datos**

# Origen de los datos

Para el desarrollo de este trabajo se seleccionó el conjunto de datos *Marvel Comic Books Dataset*, publicado en la plataforma Kaggle. Según la descripción por parte del autor, el conjunto contiene información sobre publicaciones de cómics pertenecientes al universo Marvel.

La fuente de los datos indicada es el sitio oficial de Marvel Comics,(https://www.marvel.com/comics/series).

# Contexto y ubicación geográfica

Marvel Comics es una editorial estadounidense dedicada a la publicación de historietas y al desarrollo de personajes y universos ficticios.

El conjunto de datos se relaciona con las publicaciones de esta editorial. La descripción no especifica la ubicación geográfica de cada publicación, el país de venta ni el mercado al que está dirigida. Por este motivo, Estados Unidos se considera parte del contexto institucional de Marvel.

# Características del conjunto de datos

El conjunto de datos contiene variables relacionadas con las series de cómics y sus números individuales. Se incluyen las siguientes columnas:

- **Comic name:** nombre de la serie de cómics.
- **Active years:** período durante el cual estuvo activa la serie.
- **Issue title:** título de un número individual de la serie.
- **Publish date:** fecha de publicación del número.
- **Issue_description:** descripción del contenido del número.
- **Penciler:** dibujante responsable del dibujo a lápiz.
- **Writer:** guionista original.
- **Cover artist:** artista responsable de la ilustración de portada.
- **Imprint:** sello editorial bajo el cual se publica una obra.
- **Format:** formato de publicación del cómic.
- **Rating:** clasificación por edad.
- **Price:** precio registrado para la publicación.

Estas variables permiten caracterizar las publicaciones desde diferentes perspectivas: temporal, editorial, creativa y económica. Además, posibilitan explorar la frecuencia de publicación de las series, la participación de los creadores, los formatos disponibles y la distribución de los precios.
